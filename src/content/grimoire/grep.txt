NAME
    grep - scry for words inside books

SYNOPSIS
    grep [OPTION]... PATTERN [FILE]...

DESCRIPTION
    Grep prints every line that matches PATTERN. With no FILE it searches
    standard input, so it is at home at the end of a pipe. PATTERN is a
    regular expression: . matches any character, * repeats what comes
    before it, ^ and $ anchor the start and end of a line, [abc] matches
    any one of a, b, or c.

    -i, --ignore-case      upper and lower case are the same
    -v, --invert-match     print the lines that do NOT match
    -n, --line-number      number each matching line
    -c, --count            print only how many lines matched
    -l, --files-with-matches
                           print only the names of books that match
    -r, --recursive        search every book in a room, and every room
                           inside it
    -w, --word-regexp      match whole words only
    -x, --line-regexp      match whole lines only
    -o, --only-matching    print only the matching part of each line
    -h, -H                 hide or show the book name on each line
    -q, --quiet            print nothing; succeed if anything matched
    -E                     extended expressions: ( ) | + ? are special
    -F                     the pattern is plain text, nothing special
    -e PATTERN             use PATTERN (useful if it begins with -)

EXIT STATUS
    0 if a line matched, 1 if none did, 2 if something went wrong.

EXAMPLES
    grep lionX journal          lines that mention lionX
    grep -rn Ostra /archive     every mention, with places, everywhere
    grep -c '' book             how many lines the book has
